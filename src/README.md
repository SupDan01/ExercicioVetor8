# Exercicio de Vetor 8

Programa criado para uma atividade envolvendo vetores.

### Objetivo:

Criar um menu que contenha a opção cadastrar aluno, listar aluno, consultar aluno e
sair do programa. O limite máximo de alunos que pode ser cadastrado não pode ser menor que
0 e nem maior que 100.

Foi também implementado o uso das opções excluir e alterar.

Feito usando Scanner e no Java.
